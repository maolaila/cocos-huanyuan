# Manual Checkpoint 05 — CNY / USD / VND 动态文本与金额布局

Status：`AwaitingHumanReview`

本检查点只验证 Creator 3.8.8 显示层。钱包、下注、回合、订单和结算仍使用服务端原始六位小数；
界面缩写不得改变任何权威数值。按当前 `HUMAN_CHECKPOINTS` 约束，Codex 不执行编译或预览。

## A. Room 大厅

1. 内部 `plr_* / pp_* / sid_*` 不应再铺满昵称栏；中文显示“玩家”，越南语显示“Người chơi”，
   其它语言显示“Player”。普通商户昵称继续显示，并在原宽度内省略；
2. CNY 短余额保留原数字 BMFont；超过原栏位时使用 `万/亿`，不出现小数点缺字；
3. VND 钱包显示 `N/Tr/T/NT` 和 `₫`，例如 `1Tr₫`、`1,25T₫`；
4. USD 钱包显示 `$ + K/M/B/T`，例如 `$1K`、`$1.25M`；
5. 三张房间卡的盲注、准入、最大携带从当前 `roomConfig` 渲染。文本不得覆盖“最大携带”、
   房间图片字、空闲/拥挤状态或快速开始按钮；
6. CNY 原默认 `1万/2万`、`1千/2千`、`5千/1万` 和原 `1bw/5bw` 大字风格应保持。

## B. DZPKMain 牌桌

分别使用短值、单位阈值、长值检查以下节点：玩家筹码、单次下注、底池、已归集底池、跟注金额、
五个加注预设、Slider Handle、主/边池派奖和赢家浮字。

| 币种 | 阈值样例 | 预期显示风格 |
|---|---:|---|
| CNY | `9,999 / 10,000 / 100,000,000` | 原数字、`万`、`亿`；过长时去掉无意义尾零 |
| USD | `999 / 1,000 / 1,000,000 / 1,000,000,000` | `999 / 1K / 1M / 1B`；钱包额外显示 `$` |
| VND | `999 / 1,000 / 1,000,000 / 1,000,000,000 / 1,000,000,000,000` | `999 / 1N / 1Tr / 1T / 1NT`；钱包额外显示 `₫`，小数使用逗号 |

所有 Label 必须保持单行；允许在原 UITransform 内自动缩小，不允许扩张后压住头像、牌面、按钮、
倒计时或相邻座位。CNY 能由原 BMFont 表达时不得切换字体；只有缺少 `$ / ₫ / K / M / B / T / N / Tr`
等字形的动态 Label 才局部回退 Arial。

## C. 横屏与提示

3. 设置页版本号应为短文本 `v3.8.8`；
4. 第一手、第二手、返回 Room 后金额格式保持一致，不因页面切换恢复成长数字；
5. Console 不应出现 BMFont missing glyph、Label overflow 或新红错。
